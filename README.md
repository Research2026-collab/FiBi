An interactive planning tool for adult educators and programme planners to design target group-oriented educational offers based on realistic learner personas.

Overview

The FiBi Persona Workshop supports the development of educational offers by combining user-centred planning with structured information about typical participants in adult education.

The application provides 15 personas representing diverse life situations, educational experiences and financial circumstances. These include, for example, an apprentice, a family caregiver, a retired person, a single parent, a migrant learner and a civically engaged adult.

Each persona contains information on

* life situation
* educational background
* financial circumstances
* learning interests
* barriers to participation
* preferred learning conditions

Planning Tool

Users select one persona and enter key information about a planned educational activity, including

* topic
* objectives
* format
* duration
* organisational framework

Based on these inputs, the application generates

* a draft course description suitable for programme announcements
* an internal planning document summarising how the selected persona’s needs, interests and barriers have been considered

The planning document can be transferred directly into the accompanying FiBi Material Pool.

Purpose

The tool encourages programme planning that is sensitive to different educational biographies, financial situations and participation barriers. Rather than designing courses for an abstract target group, planners are supported in considering the perspectives of concrete learner profiles during the planning process.

Intended Users

* adult education providers
* programme planners
* educational managers
* trainers
* continuing education organisations
